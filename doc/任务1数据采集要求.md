# 任务1：单视角感知质量数据采集标准（MVP版）

## 1. 采集目标

本任务用于支持固定单相机视角下的足球场景感知能力初步验证，主要覆盖：

- 人体目标检测
- 足球目标检测
- 26点人体2D骨骼点检测
- 单镜头目标跟踪
- 静止、抖动、快速运动、遮挡等场景下的基础稳定性验证

本阶段重点是验证模型在真实固定机位画面下的基础可用性，难例和精细标注可根据 MVP 验证结果后续补充。

## 2. 采集原则

- 使用最终部署或接近部署状态的固定相机机位采集。
- 尽量保持真实安装高度、视角、焦距、俯角和横摆角。
- 保留原始视频分辨率、帧率和码率。
- 不建议对视频进行裁剪、压缩、变帧率、水印叠加等处理。
- 每段视频需尽量保留相机编号、时间戳、帧号等基础信息。
- 优先采集真实比赛或训练场景。
- 本阶段以覆盖核心场景为主，复杂难例可分阶段补采。

## 3. 建议采集内容

| 数据类型 | MVP建议规模 | 用途 |
|---|---:|---|
| 原始连续视频 | 30-60分钟 | 用于检测、姿态、跟踪和稳定性初步验证 |
| 抽帧图片 | 约1000张 | 用于效果检查、难例分析和后续优化 |
| 跟踪验证片段 | 5-10段 | 用于验证单镜头ID稳定性 |
| 单段视频长度 | 10-20秒 | 覆盖连续运动过程 |
| 静止/空场片段 | 2-3段 | 用于检查误检和画面稳定性 |

## 4. 抽帧图片分布建议

| 场景类型 | 建议数量 | 说明 |
|---|---:|---|
| 常规比赛/训练 | 250张 | 覆盖普通站位、跑动、传球、防守 |
| 快速运动 | 200张 | 覆盖冲刺、射门、长传、高速球、运动模糊 |
| 多人遮挡 | 200张 | 覆盖抢球、贴身防守、禁区混战 |
| 足球难例 | 250张 | 覆盖远端小球、脚下球、空中球、遮挡球 |
| 静止/空场/负样本 | 100张 | 用于检查误检和画面抖动稳定性 |

> 以上数量为建议分布，可根据实际采集内容微调，但总量建议保持在约1000张。

## 5. 人体场景覆盖要求

人体相关画面建议覆盖：

- 正面、侧面、背面人体
- 站立、跑动、急停、转身、跳跃
- 守门员扑救
- 多人聚集、身体重叠、互相遮挡
- 远端小尺度人体
- 近端大尺度人体
- 画面边缘截断人体
- 球员、守门员、裁判、教练、替补、场边人员

## 6. 足球场景覆盖要求

足球相关画面建议覆盖：

- 地滚球
- 空中球
- 射门瞬间
- 传球瞬间
- 脚下球
- 被腿部或身体部分遮挡的球
- 遮挡后重新出现的球
- 远端小目标足球
- 高速运动模糊足球
- 靠近白线、球门网、广告牌等易误检区域的足球
- 无球但容易误检的负样本画面

## 7. 跟踪片段覆盖要求

跟踪验证片段建议覆盖：

- 球员交叉跑位
- 多人聚集后分散
- 球员短暂出画后重新进入
- 球员被遮挡后重新出现
- 同队球衣相似导致ID混淆的场景
- 足球高速运动后重新出现
- 禁区混战、角球、防守贴身等复杂场景

## 8. 静止与抖动场景要求

需采集少量静止或低运动场景，用于检查固定机位下的稳定性：

- 空场画面
- 球员站立不动
- 远端球员慢走
- 画面轻微抖动
- 光照变化场景
- 场地线、球门网、广告牌等易误检区域

## 9. 采集记录要求

每次采集需记录基础信息，用于后续数据管理、问题定位和效果分析。

### 9.1 必填信息

| 字段 | 说明 |
|---|---|
| 场地名称 | 用于区分不同采集地点 |
| 采集日期 | 用于区分不同批次数据 |
| 相机编号 | 用于区分不同机位 |
| 视频文件名 | 用于和原始视频、抽帧图片对应 |
| 分辨率 | 用于判断画面清晰度和目标尺度 |
| 帧率 | 用于分析运动模糊、跟踪稳定性 |
| 相机安装位置描述 | 如主看台、中线附近、球门后、边线高位等 |
| 比赛或训练类型 | 如正式比赛、队内训练、热身、半场训练等 |
| 球衣颜色 | 用于分析人体检测、跟踪和队伍混淆问题 |
| 天气和光照条件 | 如晴天、阴天、夜间、逆光、强阴影等 |
| 特殊情况说明 | 如遮挡、抖动、雨天、强反光、画面过暗等 |

### 9.2 选填信息

| 字段 | 说明 |
|---|---|
| 码率 | 当不同视频压缩质量差异较大时记录 |
| 相机安装高度 | 能大致记录即可，不要求精确测量 |
| 镜头焦距或变焦档位 | 仅在相机支持变焦或不同机位焦距差异明显时记录 |
| 相机俯角 | 可选，不要求精确角度 |
| 相机横摆角 | 可选，不要求精确角度 |

### 9.3 不建议强制要求

以下字段不建议作为强制采集要求：

- 精确相机俯角
- 精确相机横摆角
- 精确镜头焦距
- 精确安装高度
- 复杂相机内参或外参
- 每段视频的详细帧级事件记录

除非后续需要做相机标定、3D空间映射或跨机位几何分析，否则以上信息对本阶段感知质量验证帮助有限。

## 10. 可选标注内容

以下标注不作为 MVP 阶段强制要求，可根据验证效果和后续优化需要选择性补充。

### 10.1 图片标注

可选标注内容包括：

- 人体检测框
- 足球检测框
- 26点人体2D骨骼点
- 骨骼点可见状态
- 目标类别，如球员、守门员、裁判、场边人员
- 队伍或球衣颜色

### 10.2 连续视频标注

可选标注内容包括：

- 人体 track_id
- 足球 ball_id
- 每帧人体框
- 每帧足球框
- 遮挡、出画、重新出现等状态

## 11. 交付物

MVP阶段交付物包括：

- 原始视频文件
- 抽帧图片
- 跟踪验证片段
- 静止与抖动验证片段
- 采集记录表
- 典型难例说明

可选交付物包括：

- 图片标注文件
- 连续视频标注文件
- 详细难例分类表

## 12. 分阶段采集建议

| 阶段 | 目标 | 数据要求 |
|---|---|---|
| MVP阶段 | 验证基础可用性 | 少量真实视频、核心场景抽帧、基础跟踪片段 |
| 优化阶段 | 提升难例效果 | 补充遮挡、小球、快速运动、误检区域等样本 |
| 验收阶段 | 做正式量化评估 | 扩大数据规模，补充精细标注和完整评测集 |
