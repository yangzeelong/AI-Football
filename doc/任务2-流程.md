# 任务2：多视角空间融合流程清单

## 1. 任务目标

任务2的目标是将 C1-C4 多路固定相机中的 2D 观测结果，融合到统一的足球场世界坐标系中，输出人和球的全局三维轨迹。

整体流程如下：

```text
多相机视频采集
-> 多相机时间同步
-> 相机标定
-> 接入单相机2D结果
-> 单相机地面坐标映射
-> 跨镜头目标关联
-> 多视角三角化
-> 3D轨迹滤波
-> 回投影校验
-> 输出全局3D轨迹
```

---

## 2. 步骤1：采集多相机原始视频

### 要做什么

使用 C1-C4 固定相机同时采集足球场视频。

每台相机需要保持：

- 固定位置
- 固定角度
- 固定焦距
- 固定分辨率
- 固定帧率
- 固定裁剪区域

### 需要注意

相机安装完成后，不要随意移动相机，也不要改变焦距、分辨率或裁剪区域。否则后续标定参数会失效。

### 产出

```text
C1原始视频
C2原始视频
C3原始视频
C4原始视频
相机安装记录表
```

### 示例格式

```json
{
  "camera_id": "C1",
  "video_file": "C1_001.mp4",
  "resolution": [3840, 2160],
  "frame_rate": 50,
  "installation_position": "球门后方左侧高位",
  "installation_height_m": 6.5,
  "focal_length_or_zoom": "fixed",
  "note": "安装后未移动"
}
```

## 3. 步骤2：完成多相机时间同步

### 要做什么

确认 C1-C4 的视频在时间上是对齐的。

也就是说，同一时刻发生的动作，在所有相机中应该对应到同一个时间戳或同一帧附近。

### 建议做法

采集一个明显的同步事件，例如：

- 场地中央挥手
- 踢球瞬间
- LED闪烁
- 哨声配合明显动作
- 快速起跳或落地动作

### 需要检查

- 每路视频开始时间
- 每帧时间戳
- 帧率是否一致
- 是否丢帧
- 各相机之间是否存在时间偏移

### 产出

```text
多相机同步记录文件
同步校验片段
时间偏移量记录
```

### 示例格式

## 4. 步骤3：完成相机标定

### 要做什么

为每台相机计算标定参数，让算法知道每台相机和真实球场之间的关系。

标定需要得到：

- 内参
- 畸变参数
- 外参
- 地面单应矩阵
- 回投影误差

### 标定画面要求

每台相机需要保留清晰标定画面，画面中尽量包含：

- 球门柱底部
- 球门线
- 禁区线
- 小禁区线
- 边线
- 中线
- 点球点
- 场地线交点

### 需要注意

安装位置、高度、俯角、横摆角只能作为初值，最终以标定结果为准。

### 产出

```text
每台相机的标定文件
标定点对应关系文件
回投影误差报告
```

## 6. 步骤5：计算单相机地面坐标

### 要做什么

先把每个相机画面中的球员位置映射到真实球场地面。

MVP阶段建议使用球员检测框底部中心点作为脚下点：

```text
foot_point_2d = [bbox_x + bbox_w / 2, bbox_y + bbox_h]
```

然后使用地面单应矩阵，将画面点映射到球场地面坐标：

```text
image_point -> world_point_z0
```

### 适用对象

- 球员
- 守门员
- 裁判
- 地滚球，可作为低成本近似

### 不适用对象

- 空中球
- 跳起的人体关键点
- 需要真实高度的目标

### 产出

```text
每台相机下的单相机地面坐标结果
```

### 示例格式

```json
{
  "camera_id": "C1",
  "timestamp": 123456.789,
  "track_id": 7,
  "type": "player",
  "image_point": [350, 330],
  "ground_position": [12.4, 31.8, 0.0],
  "confidence": 0.86,
  "method": "ground_homography"
}
```

## 7. 步骤6：跨镜头目标关联

### 要做什么

判断不同相机中看到的目标是否是同一个真实目标。

例如：

```text
C1中的track_id=7
和
C3中的track_id=12
是否是同一个球员
```

### MVP建议规则

优先使用几何和运动规则：

- 时间戳是否对齐
- 地面坐标距离是否接近
- 运动速度是否合理
- 运动方向是否连续
- 目标类别是否一致
- 回投影误差是否较小

### 产出

```text
跨镜头关联结果
局部track_id到全局global_id的映射关系
```

### 示例格式

```json
{
  "timestamp": 123456.789,
  "global_id": 17,
  "type": "player",
  "associations": [
    {
      "camera_id": "C1",
      "track_id": 7
    },
    {
      "camera_id": "C3",
      "track_id": 12
    }
  ],
  "confidence": 0.88,
  "method": "geometry_motion_rule"
}
```

## 8. 步骤7：多视角三角化3D坐标

### 要做什么

当同一个目标在至少两个相机中同时可见时，可以使用多视角三角化计算3D坐标。

### 适用对象

- 空中足球
- 需要高度信息的目标
- 多相机都能看到的目标

### 足球建议

足球需要区分：

- 地滚球：可先按地面点处理
- 空中球：使用多相机三角化
- 单相机可见：只输出低置信度或预测状态，不强行输出高可信3D

### 产出

```text
三角化3D坐标结果
```

### 示例格式

```json
{
  "timestamp": 123456.789,
  "global_id": 1,
  "type": "ball",
  "position_3d": [10.2, 24.6, 1.4],
  "source_cameras": ["C1", "C2", "C4"],
  "confidence": 0.82,
  "method": "triangulation"
}
```

---

## 9. 步骤8：3D轨迹滤波

### 要做什么

对连续帧的3D坐标进行平滑处理，减少检测误差、抖动和短暂丢失带来的轨迹跳变。

### 可以处理的问题

- 3D位置抖动
- 短暂遮挡
- 单帧异常点
- 速度突然不合理
- 多相机组合切换导致的轨迹跳动

### 推荐MVP方法

- Kalman Filter
- 简单速度约束
- 短时间缺失预测
- 异常点剔除

### 产出

```text
滤波后的3D轨迹
目标状态序列
```

### 示例格式

```json
{
  "timestamp": 123456.789,
  "global_id": 17,
  "type": "player",
  "raw_position_3d": [12.1, 31.5, 0.0],
  "filtered_position_3d": [12.4, 31.8, 0.0],
  "velocity": [1.2, 3.4, 0.0],
  "state": "tracked",
  "confidence": 0.9
}
```

## 10. 步骤9：回投影校验

### 要做什么

将计算出的3D点重新投影回各个相机画面，检查是否落在原始检测目标附近。

这是判断任务2结果是否可信的关键步骤。

### 检查内容

- 回投影点是否落在人体框底部附近
- 足球回投影点是否落在足球检测框附近
- 回投影误差是否过大
- 哪些相机误差大
- 是否存在标定错误、同步错误或关联错误

### 产出

```text
回投影校验结果
回投影可视化视频或图片
异常案例记录
```

### 示例格式

```json
{
  "timestamp": 123456.789,
  "global_id": 17,
  "type": "player",
  "position_3d": [12.4, 31.8, 0.0],
  "reprojection": [
    {
      "camera_id": "C1",
      "projected_point": [351, 329],
      "observed_point": [350, 330],
      "error_px": 1.4
    },
    {
      "camera_id": "C3",
      "projected_point": [912, 604],
      "observed_point": [920, 610],
      "error_px": 10.0
    }
  ],
  "mean_error_px": 5.7,
  "quality": "pass"
}
```

## 11. 步骤10：输出全局3D轨迹

### 要做什么

整合跨镜头关联、三角化、滤波和回投影校验结果，输出最终全局轨迹。

### 产出

```text
全局3D轨迹文件
轨迹质量报告
失败案例记录
```

### 示例格式

```json
{
  "timestamp": 123456.789,
  "global_id": 17,
  "type": "player",
  "position_3d": [12.4, 31.8, 0.0],
  "confidence": 0.87,
  "source_cameras": ["C1", "C3"],
  "state": "tracked",
  "reprojection_error_px": {
    "C1": 3.2,
    "C3": 4.1
  }
}
```

| 交付物 | 说明 |

| 跨镜头关联结果 | 局部track_id到全局global_id的映射 |

| 回投影校验结果 | 3D结果投回画面的误差统计 |
| 回投影可视化文件 | 方便人工检查3D结果是否靠谱 |
| 失败案例记录 | 标定、同步、关联、检测和轨迹异常案例 |
