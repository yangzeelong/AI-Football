# 任务 1 Roadmap：单视角感知质量

## 目标

任务 1 的目标是把单视角视频稳定产出可被任务 2 使用的 2D Observation，包括人体框、足球框、26 点骨骼、单镜头 ID、置信度和状态。

整体链路：

```text
视频输入 -> RF-DETR/YOLO 人球检测 -> 人体跟踪 -> RTMPose/WholeBody 26点骨骼 -> 关键点稳定 -> 足球专用跟踪 -> JSONL输出 -> 质量评估
```

## 周会后优先级调整

当前 MVP 已经完成检测、26 点骨骼、人体 track、足球 track、JSONL、label-aware 报告和参数 sweep。后续优化优先级调整为：

1. 关键点稳定性：先让人体关键点在静止、慢速、快速动作下更稳定，避免业务模型直接吃到抖动点。
2. 足球检测与跟踪：再集中处理漏检、错检、多球误检，以及足球和人体重合时的遮挡问题。
3. 场景验证与接口冻结：最后把静止抖动、快速运动、遮挡三类场景的报告和输出 schema 固化。

- 26 keypoints schema

- JSONL 输出

交付物：

- 可视化视频
- smoke test 结果

## 第 2 阶段：26 点骨骼质量确认，1 周

目标：确认 26 点定义和输出顺序能服务后续动作分析。

状态：基础链路已完成，后续重点并入第 3 阶段关键点稳定性专项。

重点：

- 核对 26 点顺序
- 检查左右脚脚尖、脚跟是否稳定
- 检查 `neck / pelvis / thorax` 虚拟点是否合理
- 给低置信度点加 `missing / low_confidence` 状态
- 输出关键点可视化编号图，便于业务人员确认

验收：

- 每个人固定输出 26 点
- 点位顺序稳定
- 脚部关键点能区分左右脚
- 低质量点不会被误当成高置信观测

## 第 3 阶段：关键点稳定性专项，1-2 周

目标：降低人体关键点抖动、跳变和短时缺失，让 26 点输出更适合后续动作分析。

重点：

- 先区分人体处于静止还是运动状态，再走不同的关键点稳定逻辑
- 静止状态优先压制手腕、脚腕等高抖点，运动状态则放宽平滑，避免明显滞后
- 按 person track 聚合每个人的 26 点时序
- 统计每个关键点的抖动、速度、加速度、缺失率和低置信比例
- 对关键点加 confidence-aware smoothing，例如 One Euro Filter 或 Kalman
- 对短时缺失点做预测或插值，并标记 `predicted`
- 检查左右脚、脚跟、脚尖、膝盖等业务敏感点的稳定性
- 避免快速运动中过度平滑导致明显滞后

建议指标：

- 每个关键点平均置信度
- 低置信关键点比例
- 缺失关键点比例
- keypoint motion p95
- 静止片段关键点像素标准差
- 肢体长度波动比例
- 平滑前后延迟和抖动对比

交付物：

- 关键点稳定性报告
- 平滑前后对比 JSONL
- 平滑前后 render 视频
- 问题帧列表：低置信、跳变、缺失、左右点疑似交换

## 第 4 阶段：足球检测与专用跟踪，1-2 周

目标：足球小目标、高速、遮挡情况下尽量不断轨。

重点：

- RF-DETR/YOLO 足球检测效果评估
- 基于 label 的阈值 sweep，降低无球误检和单球多检
- 足球候选打分：置信度、尺寸、ROI、轨迹预测距离、脚部关键点邻近关系
- 足球 tracker 参数调优
- 丢球后短时预测
- 处理足球和人体重合：短时遮挡预测，不简单删除人体框内候选球
- 排除误检，比如鞋、白线、反光点、远端噪声
- 判断是否需要标注少量足球数据做微调

建议指标：

- 足球检测召回率
- 足球误检率
- 单球视频多球帧比例
- 无球视频误检帧比例
- 连续丢失最长帧数
- 丢失后恢复时间
- 预测轨迹跳变距离

交付物：

- 足球轨迹 JSONL
- 足球轨迹可视化
- 足球错误帧挖掘报告
- 是否需要微调的判断报告

## 第 5 阶段：人体检测与跟踪稳定性，1 周

目标：在关键点稳定和足球专项之前/之后持续保证人体 ID 尽量连续。

重点：

- 人体框置信度阈值调优
- ROI 过滤联调
- 遮挡后 ID 恢复测试
- 统计 ID switch、track fragment
- 必要时对人体框中心做轻量平滑

验收：

- 单人 ID switch 次数下降
- track fragment 变少
- 遮挡后尽量恢复原 ID
- 人体框抖动不明显影响关键点输入

## 第 6 阶段：三类场景验证，1 周

目标：专门验证任务需求里的三种场景。

场景：

- 静止抖动
- 快速运动
- 遮挡

每类输出：

- 原视频
- 可视化结果
- JSONL
- 指标统计
- 问题帧截图

建议验收表：

| 场景 | 主要指标 | 目标 |
| --- | --- | --- |
| 静止 | 关键点像素标准差 | 越低越好，先建立基线 |
| 快速运动 | 漏检率、轨迹断裂 | 不出现长时间断轨 |
| 遮挡 | ID switch、恢复帧数 | 遮挡后尽量恢复原 ID |
